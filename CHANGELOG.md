# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-01-20

### Changed
- Forked from [greybax/cordova-plugin-proguard](https://github.com/greybax/cordova-plugin-proguard)
- Renamed plugin to `community-cordova-plugin-proguard`
- Updated package structure to match community plugin conventions
- Updated license header to MIT
- Enhanced proguard-custom.txt with additional rules for Firebase, AdMob, SQLite, and other common libraries

### Added
- Support for Firebase Analytics and Crashlytics
- Support for Google Play Services
- Support for AdMob
- Support for SQLite plugins
- Support for Ionic WebView
- Support for Cordova Support Library annotations

### Credits
- Original plugin by Aleksandr Filatov (greybax)
- All original contributors to cordova-plugin-proguard
